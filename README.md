# 🔍 Google-Style Portfolio

A modern, responsive portfolio website designed with the iconic **Google Search** aesthetic. This project features dynamic theme switching, a custom-built Google-style navbar, and a fully functional search-bar layout.

## ✨ Features

* **Google Search UI:** A pixel-perfect recreation of the Google Search results interface.
* **Dynamic Dark Mode:** Seamlessly switch between Light and Dark themes with a real-time observer.
* **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop views.
* **Active Navigation:** Underline animations and active states that mimic Google's tabs (All, Images, News, etc.).
* **Custom Components:** Reusable Footer, Navbar, and Search-bar components with inline-style protection for production stability.

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Hooks & Functional Components)
* **Bundler:** Vite (for ultra-fast development)
* **Routing:** React Router v6
* **Deployment:** Vercel
* **Styling:** CSS3 & Inline Styles (for specificity protection)

## 📦 Installation & Setup

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Bittu169/Google-portfolio.git](https://github.com/Bittu169/Google-portfolio.git)

2. **Navigate to the project folder:**
   ```bash
   cd Google-portfolio
3. **Install dependencies:**
   ```bash
   npm install
4. **Start the development server:**
   ```bash
   npm run dev

## 📂 Project Structure
